## ✨ Features & Architecture

### 🌐 1. Website Frontend (`/WEBSITE FRONTEND`)
- **Interactive Multi-Theme Hero Card**: Features dynamic 3D tilt movement, ambient glows, frosted glass paneling, and the **3D Tensora Background Logo Watermark**.
- **Four Core Engineering Pillars**:
  - 💻 **Technology & Engineering**: Web, Mobile & Scalable Microservices.
  - 🎮 **Gaming & Simulation Systems**: Bespoke FiveM Roleplay, QBCore/ESX Frameworks, & NUI Game HUDs.
  - 🎨 **Creative 3D & Visual CGI**: Photorealistic Rendering, PBR Texturing, & WebGL Configurators.
  - 🎬 **Brand Identity & Media**: Vector Branding, 4K Cinema Editing, & Color Grading.
- **Service & Project Showcases**: Case studies, interactive cards, client testimonials slider, and contact forms.

### 📊 2. Dashboard Frontend (`/DASHBOARD FRONTEND`)
- **Admin & Client Portals**: Comprehensive dashboard layouts for project tracking, invoices, client communications, attendance, and analytics.
- **Role-Based Access Control (RBAC)**: Distinct permissions for system administrators, team members, and clients.

### ⚙️ 3. Microservices Backend (`/BACKED`)
- **Express.js API Engine**: Modular controller and routing structure handling auth, client management, projects, invoices, tasks, and system metrics.
- **Authentication Middleware**: JWT token validation, role-based checks, and Firebase authentication integration.

## 🚀 Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) (v18 or higher) installed on your machine.

### Installation & Running Locally

#### 1. Website Frontend
```bash
# Navigate to Website Frontend directory
cd "WEBSITE FRONTEND"

# Install dependencies
npm install

# Start local development server (runs on http://localhost:3000)
npm run dev
```

#### 2. Dashboard Frontend
```bash
# Navigate to Dashboard Frontend directory
cd "DASHBOARD FRONTEND"

# Install dependencies
npm install

# Start local development server
npm run dev
```

#### 3. Microservices Backend
```bash
# Navigate to Backend directory
cd "BACKED"

# Install dependencies
npm install

# Start API server
npm start
```

---

## 📦 Production Build

To build the website frontend for production deployment:

```bash
cd "WEBSITE FRONTEND"
npm run build
```

The output bundle will be generated inside the `dist/` directory, optimized and ready for hosting.
